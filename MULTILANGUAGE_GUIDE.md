"# Multi-Language Support Guide for Websites\n\n## Best Practices Overview\n\n### 1. **Recommended Approach: i18next + react-i18next**\n\nThis is the industry-standard solution for React applications.\n\n#### Setup Steps:\n\n```bash\nnpm install i18next react-i18next\n```\n\n#### Project Structure:\n```\nsrc/\n├── App.jsx\n├── main.jsx\n├── index.css\n├── i18n.js          # i18n configuration\n└── locales/\n    ├── en.json      # English translations\n    ├── fr.json      # French translations\n    └── es.json      # Spanish translations\n```\n\n#### Configuration (src/i18n.js):\n```javascript\nimport i18n from 'i18next'\nimport { initReactI18next } from 'react-i18next'\nimport en from './locales/en.json'\nimport fr from './locales/fr.json'\nimport es from './locales/es.json'\n\ni18n\n  .use(initReactI18next)\n  .init({\n    resources: {\n      en: { translation: en },\n      fr: { translation: fr },\n      es: { translation: es }\n    },\n    lng: 'en', // default language\n    fallbackLng: 'en',\n    interpolation: {\n      escapeValue: false // React already escapes values\n    }\n  })\n\nexport default i18n\n```\n\n#### Usage in Components:\n```jsx\nimport { useTranslation } from 'react-i18next'\n\nfunction MyComponent() {\n  const { t, i18n } = useTranslation()\n  \n  // Change language\n  const changeLanguage = (lng) => {\n    i18n.changeLanguage(lng)\n  }\n\n  return (\n    <div>\n      <h1>{t('welcome')}</h1>\n      <select onChange={(e) => changeLanguage(e.target.value)}>\n        <option value=\"en\">English</option>\n        <option value=\"fr\">Français</option>\n        <option value=\"es\">Español</option>\n      </select>\n    </div>\n  )\n}\n```\n\n### 2. **Translation Files Format (src/locales/en.json)**:\n```json\n{\n  \"welcome\": \"Welcome to Reiki Azul\",\n  \"menu\": \"Menu\",\n  \"about\": \"About Us\",\n  \"services\": \"Our Services\",\n  \"contact\": \"Contact Information\"\n}\n```\n\n### 3. **Alternative Approaches**\n\n#### a) Next.js with Built-in i18n:\n```bash\nnpm install next-intl\n```\n- Automatic locale detection\n- URL-based routing (/en, /fr, }\n}\n\n// Fetch based on user's browser language\nfetch('/locales.json').then(res => res.json())\n```\n\n#### c) Using a Translation Management Platform:\n- **Crowdin** - Professional platform with app\n✅ Never hardcode strings in JSX (use t() function)\n✅ Handle RTL languages (Arabic, Hebrew) properly\n✅ Consider text expansion (German is ~20% longer than English)\n✅ Test with all target languages before launch\n✅ Provide fallback translations for missing keys\n✅ Use pluralization rules for dynamic content\n✅ Implement date/time formatting per locale\n✅ Consider using a translation management platform for workflows\n\n### 5. **RTL Support Example**\n```javascript\n// In i18n.js\ni18n.dir('ar') // Set direction based on language\n```\n\n### 6. **Date/Time
